# stock-analysis-tool
A python based stock analysis tool that compares two stocks using historical market data. It calculates returns and volatility and visualizes performance over a 1 month period.

##Features
- Fetches real stock data using Yahoo Finance.
- Calculates daily returns, average return and volatility.
- Generates a graph to visually compare two stocks side by side
- Displays a summary report directly on the chart

##Tech Used
- Python
- yfinance
- Matplotlib
